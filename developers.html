Why developers switch

Most parsers hand you JSON and a shrug.

A traditional parser

  • document → JSON
  • “trust me”
  • no source spans
  • no versions, no proof

When the output is wrong, you debug blind.

The Orves API

  • document → canonical objects
  • evidence + source spans
  • versions + resolution states
  • certificate + public verification

Every response can be traced, reproduced and proven.

Guarantees

What the API promises — and shows.

Deterministic

Same input, same version, same output. Idempotency keys on every mutating call.

Replayable

Every result can be re-derived from the canonical model — reproduce exactly what changed, and what did not.

Honest states

UNKNOWN and ABSTAINED are first-class API states with reasons — never silent nulls.

Certified responses

Every artifact returns with a certificate ID. Verification is designed to be public and account-free.

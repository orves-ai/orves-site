FAQ

자주 묻는 질문.

크레딧이 무엇인가요?

크레딧은 모든 Orves 제품의 공통 과금 단위입니다. 크레딧은 수행된 작업 — 한 쪽 파싱, 검증 가능한 지식 생성 — 으로 소모되며, 토큰으로 소모되지 않습니다.

크레딧은 제품 간에 공유되나요?

네. Orves 크레딧은 모든 Orves 제품이 공유하는 하나의 잔액입니다. 각 제품은 단독으로 씁니다 — 문제가 있는 곳에서 시작하고, 다음 문제가 생기면 다른 것을 더하세요.

포함된 크레딧을 넘기면 어떻게 되나요?

포함된 크레딧을 넘는 사용은 요금제의 추가 크레딧 단가로 청구됩니다. 잔액이 떨어지면 API 호출이 일시 중지됩니다 — 아무것도 삭제되거나 사라지지 않습니다. 충전하면 처리가 재개되며, 청구는 멱등이라 재시도로 이중 청구되지 않습니다.

나중에 요금제를 바꿀 수 있나요?

네. 무료로 시작해 워크로드가 커지면 Starter나 Pro로 옮기세요. 엔터프라이즈 거버넌스나 배포 옵션이 필요하면 영업팀에 문의하세요.

motor de ingestão · parse · piloto

Entra sem estrutura. Saem dados estruturados.

O Orves Parse transforma documentos complexos em dados estruturados e ligados à fonte com uma única chamada autenticada de API. Assíncrono por projeto: envie o documento, consulte o job, pegue o resultado. API independente, em piloto privado; a primeira camada, não o destino final.

O problema

O parsing é onde os sistemas de IA começam a mentir.

A maioria dos parsers achata os documentos até virarem uma cadeia de texto. Estrutura, geometria, tabelas e procedência são destruídas antes de qualquer modelo ver o conteúdo — e nenhum passo seguinte recupera o que o parsing perdeu.

tabelas achatadasordem de leitura perdidanotas de rodapé órfãssem spans de origemerros de leitura silenciosos
o padrãodocumento→"uma cadeia enorme"→LLM→confiante, e errado
com o Parsedocumento→artefatos + spans→LLM→fundamentado, conferível
O que ele produz

Estrutura, não sopa.

Saída estruturada

  • títulos
  • tabelas
  • ordem de leitura

O que o piloto devolve hoje: a estrutura do documento preservada como Markdown limpo.

Jobs assíncronos

  • id do job
  • polling
  • idempotência

202 ao enviar, consulte o job, pegue o resultado. Um parse que falha nunca é cobrado.

Ligado à fonte por projeto

  • procedência
  • versionado
  • roadmap

A saída continua presa ao documento que a produziu. Elementos tipados, coordenadas e certificados são a direção publicada — anunciados só conforme forem ao ar.

Como funciona

entra um PDF→Parse→job→resultado→saída estruturada
Me mostra

Uma resposta, exatamente como a API devolve.

Esquerda: a página. Direita: o que você recebe — a estrutura do documento preservada como Markdown limpo e estruturado.

GET /v1/parses/{id}/result
# 200 OK
{ "markdown": "# Q2 Report\n\n## Revenue by segment\n\n| Segment | Q2 |\n| --- | --- |\n| Cloud | 104.2 |\n| Devices | 61.8 |\n\nRenewal is scheduled for…" }

Resposta do contrato do piloto ao vivo. Átomos de estrutura tipados com geometria e coordenadas são a direção publicada — anunciados quando forem ao ar, nunca antes.

Benchmarks

Medido antes de afirmado.

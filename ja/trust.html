Trust

製品ではなく、性質です。

価格表に「認証」という項目はありません — すべてを貫いているからです。Orves が生み出すすべての成果物は、検証可能な証明書を携えるように作られており（現在はパイロット中）、独立した第三者が完全性と来歴を確認するために必要なものを含んでいます。アカウント不要の公開検証エンドポイントは、パイロットのロールアウトとともに提供されます。

あらゆる場所で

すべての工程で認証。

製品何が認証されるか
Parseすべてのパース — バージョン、入力、出力、出典スパン設計済み · パイロット中
Knowledgeすべてのナレッジオブジェクト、主張、回答 — バージョングラフ、証跡の連鎖、棄権とともに開発中
Vault保管、アクセス、監査イベント — 端から端まで認証できるよう設計開発中
更新新しい証跡の受け入れと再裁定のすべて — 完全な系譜つきでパイロット
性質

Orves のすべての結果が携えるもの。

来歴

すべての事実が、その正確な出典までたどれます。「これはどこから来たのか」には、いつでも答えがあります。

系譜

すべての結果は、それを生んだ各工程をさかのぼれます — 一段ごとに記録され、一段ごとに確認できます。

バージョン管理

成果物と知識はバージョンを携えます。訂正は履歴を伴う新しい項目であって、静かな書き換えではありません。

証跡

主張は、それを支える証跡とともに提供されます — 証跡が足りないときは解決状態とともに。

統制

判断なしに入るものも変わるものもありません。採点された受け入れ、解決規則、追記専用の台帳。

検証

すべての結果が、独立した検証に必要な証跡を携えます。アカウント不要の公開検証は、パイロットのロールアウトとともに提供されます。

保証

契約が約束すること。

お客様が買うのは結果です。それがどう作られるかの責任は私たちが負います。以下は、すべての出力に伴う保証です — 背後の機構の説明ではなく、契約の性質です。

追跡可能

すべての結果は、それを支える出典までさかのぼれます。

バージョン管理

すべての結果が、それを生んだ製品・スキーマ・実行バージョンを示します。

検証可能

結果は、完全性と来歴を検証するために必要な証跡を携えます。

静かな書き換えなし

変更は、以前の履歴を保ったまま、識別可能な新しいバージョンを生みます。

失敗を明示する

システムは、欠けている証跡、劣化した処理、未解決の状態を隠さずに報告します。

監査可能

実行記録、変換、消費を確認し、突き合わせられます。

特定の実装ではなく、契約によって保証されます。

仕組み

発行する。記録する。検証する。

01

発行

各製品は、自らが行うすべての変換について証明書を発行します — 署名され、ハッシュ化され、入力と出力に結びついています。

02

記録

台帳は追記専用で保存し、以前の履歴を保ちます。訂正は系譜を伴う識別可能な新しいバージョンであって、静かな編集ではありません。

03

検証

すべての証明書が、独立した第三者が確認するために必要なものを携えます。アカウント不要の公開検証エンドポイントはパイロットのロールアウトとともに提供されます — ベンダーとの関係より長く続く信頼です。

誠実さ

「分かりません」と言える唯一のプラットフォーム。

誤りではなく、意図的な判断
証跡が足りないとき、Orves は棄権します。

すべての主張が解決状態を携えます。CERTIFIED は証跡がそこにあるという意味です — 読んでください。ABSTAINED は証跡がないという意味で、どのモデルもその空白を流暢さで埋めることはできません。Orves は事実を捏造しません。

# the same API, telling the truth
{ "claim": "renewal_term",
  "state": "ABSTAINED",
  "reason": "insufficient_evidence" }

{ "claim": "policy_owner",
  "state": "CERTIFIED",
  "evidence": [{ "span": "p14 §2.3", "sha256": "9c41…" }] }

FAQ

なぜ認証は製品ではないのですか。

決済会社から「消込」をオプションとして買わないのと同じ理由です。認証はプラットフォームの動き方であって、カートに追加するものではありません。すべての成果物は認証つきで提供されます — 常に含まれています。

Orves の外で作られた成果物を認証できますか。

現時点ではできません。認証はプラットフォームが生み出すものを対象とします。他所で作られた成果物の認証が本当に必要とされるようになれば、独立した製品になる可能性があります — その判断は需要にもとづいて行われ、ロードマップのスライドで行われることはありません。

証明書は誰が検証できますか。

設計上、誰でもできます — アカウントも費用も不要です。公開検証エンドポイントはパイロットのロールアウトとともに提供されます。今日でも、すべての証明書が独立した確認に必要なものをすでに携えています。

すべての回答の出どころが分かる AI システムを構築しましょう。

15,000 の無料クレジットつきでアカウントを作成し、今日から API キーを発行できます。Parse はプライベートパイロット中です。Knowledge と Vault は提供が始まり次第続きます。

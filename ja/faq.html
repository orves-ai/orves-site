FAQ

率直にお答えします。

プラットフォーム全体を導入する必要がありますか。

いいえ。Parse は単独で成立します。多くのチームはまず Parse を導入し、各ソースが単独で説明可能である必要が生じたときに Trace を、答えがソース同士の関係に依存するときに Neuro を追加します。すべて従量制です。課題のある場所から始め、必要に応じて組み合わせてください。

Orves は自社の知能に囲い込みますか。

むしろ逆です。Trace は信頼するどのパーサーの出力でも受け取り、この連鎖が生み出すものはお客様が所有する資産です。検索、ファインチューニング、学習データなど、選んだどのモデルにもそのまま使えます。Orves が配信することは選択であり、要件ではありません。

「検証可能」とはどういう意味ですか。

情報の出どころ、その裏づけとなる証跡、元の文書のどこにあるか、そのバージョンと履歴を検証できます。追記専用の台帳上ですべての変換を認証し、アカウント不要の公開検証を提供することが設計上の方向であり、ロールアウトとともに提供されます。

Orves Trace は何を生み出しますか。

ソースごとに検証可能な結果が1つ。含まれるすべての主張が、由来する正確なスパンに結び付き、著者情報、限定条件、ソース内の関係、そしてソースが主張を裏付けない箇所には明示的な ABSTAINED を伴います。ソース横断の関係は Orves Neuro が担い、これらの結果の上で動作します。

ベンチマークの数値はどこから来ますか。

バージョン管理されたゴールドセットに対する事前登録評価からです。n と混同行列も併記します。数値がこのサイトに現れるのは、その手続きを通過した後だけです — それまでは正直な状態が表示されます。

Orves はどのように提供されますか。

API のみです。インストールも、ホスティングも不要です。軽量な SDK は利便性のために用意していますが、プラットフォームはサーバー側で動きます。

Orves は RAG スタックですか。

いいえ。RAG はその上に構築できるものの一つです。Orves は、RAG スタックが場当たり的に扱っている検証可能な知識の層を統治します。

すべての回答の出どころが分かる AI システムを構築しましょう。

15,000 の無料クレジット付きでアカウントを作成し、今日から API キーを発行できます。Parse はプライベートパイロット中、Trace と Neuro はローンチ時に開きます。

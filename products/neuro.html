The problem

Each document is understood. The whole never is.

Every source gets read in isolation and filed away — so nobody sees that two reports name the same company differently, that July's call already superseded May's forecast, or that the conclusion everyone is citing rests on a source another one contradicts. The understanding that matters lives between the documents, and nothing holds it.

Why Neuro exists

Trace reads one source. Neuro reads the whole.

Parse structures each source. Trace analyses one source at a time and never sees another — which is exactly why its results are reproducible. Neuro is where those independent results meet: it evaluates each new source-level result against the relevant Corpus state and discovers the relationships no single document declares, each one traceable back to the sources that support it.

Disagreement, preserved

Contradictions are knowledge, not errors.

Two institutions forecast the same indicator and disagree. Trace analysed each source on its own and never saw the other; Neuro is what notices they are about the same subject. It records the conflict and keeps both — with author, date and evidence — instead of averaging them, overwriting one, or manufacturing consensus.

Relationships across sources

A later source may update an earlier position, contradict another institution, refine a prior claim or introduce an unrelated view on the same topic. Trace captures these relationships within each source, carrying scope: within_source. Neuro discovers them across the Corpus, carrying scope: cross_source — the same vocabulary at two scopes, never mixed and never silently promoted from one to the other.

Inside a Corpus

More than files. More than vectors. More than a graph.

A Corpus is the persistent collection of source-level results analysed by Neuro — the sources themselves, what Trace established about each one, and the cross-source understanding built on top. You create a Corpus, add sources to it and govern who can reach it; Neuro is what studies it. The knowledge graph is a capability inside Neuro — not the product.

What Neuro runs on

Neuro is built on Trace. Every relationship leads back to evidence.

Neuro does not read documents. It works exclusively on knowledge grounded by Trace — claims that already carry their span, author, qualifiers and epistemic state. That dependency is the guarantee: a cross-source relationship is only as defensible as the source-level results underneath it, so Neuro never accepts raw text, loose chunks, embeddings or claims without provenance.

What each product needs

  • Parse — use it on its own
  • Trace — Orves Parse output, or your own compatible parser
  • Neuro — Trace-grounded results, always

Trace grounds the claims. Neuro grounds the relationships between them.

What that buys you

  • one uniform level of provenance across the whole Corpus
  • no relationship built on text nobody checked
  • every cross_source relationship traceable to two source-level results
  • reproducible inputs — the same source always grounds the same way

The dependency is not a limitation. It is what makes the relationships defensible.

Send a source, get the whole chain
your source→Parse — if the source needs structuring→Trace — grounded, one source at a time→Neuro — related across the Corpus

Neuro is a separate product, not a separate errand: send a source and the chain runs for you; bring your own parser output and it starts at Trace; bring a Trace result you already have and it starts at Neuro. You are charged only for the steps that actually run — Neuro never charges twice for an existing Trace result. What never changes is the contract: nothing reaches Neuro ungrounded.
